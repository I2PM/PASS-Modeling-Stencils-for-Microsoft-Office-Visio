Release Notes 1.1.0-R
2026-10-13

	Major release: besides several new modeling features, almost the complete macro code has been reviewed, bug-fixed, and stabilized.

	New Features and major Improvements:
		- New: Semantic Check (AI): checks the labels of the current page or of the whole model against the PASS naming conventions with the help of a large language model (Anthropic Claude, OpenAI, UniGPT, other OpenAI-compatible or local services, or a manual mode via the clipboard). You are asked before any labels are sent; API keys are only stored for your Windows user.
		- New: Aspect-oriented modeling (turn on with "Activate Aspects" in the Extended Modeling Functions)
			- Subjects can be declared "Aspect Subjects": their behavior is meant to be injected into other process models at run time. Aspect Subjects have their own symbol, color, and <<ASPECT>> label.
			- New "Edit Aspect Definition" editor (context menu of an Aspect Subject) to declare where and how the aspect is injected (injection points and execution modality) and which data it needs to access
			- Aspects are exported to OWL according to the aspect-injection extension of the Standard-PASS-Ontology
				- https://github.com/ThoEJ/aspect-injection-pass-ont
			- The Model Check warns about incomplete aspect definitions
		- New: "Generate Interface SID": creates the counterpart SID for selected interface subjects. Both pages stay linked: messages, message connectors, and subject names are mirrored automatically, and differences can be re-synchronized.
		- New: OWL export now also available as JSON-LD (Export menu: "Generate OWL-XML" and "Generate OWL-JSON-LD")
		- Reworked ribbon: automatic compact layout for smaller screens, regrouped buttons, keyboard shortcuts (Alt, A, P), tool tips for all buttons, and a new "Help / About" button
		- Subject Split rebuilt: a split is now done completely or not at all (if anything fails, the whole split is undone)
		- Major improvements for Model Check and Simple Simulation (SiSi)
			- A model is now checked together with all its extension layers (fewer false warnings)
			- More correct chance and time calculations (receive chances, time-outs, loops, triggers, several answers to one request)

	Minor Improvements and Bug Fixes:
		- Reviewed and fixed the event handling on SID, SBD, and data definition pages (more robust, fewer runtime errors)
		- OWL export: several wrong values and crashes fixed; transitions now always refer to the correct states, also on copied or renumbered pages
		- Word and PowerPoint export: problems no longer abort the export, and the model is left unchanged
		- Gantt Chart Generator reviewed and improved
		- Dialogs no longer lose data when loading fails
		- Transitions to the end point of a choice segment path are now drawn straight
		- Quotation marks in subject names are handled correctly when renaming
		- General code clean-up for more stability

2016-07-16: Release Notes 0.7.0-R

Important: v0.7.0 is not backwards compatible with process models created with earlier versions, especially due to the new message modeling. The conversion will be problematic at best and should be conducted without active macros. You may lose message information in particular. In important cases please contact: matthes.elstermann@web.de

Changes:

- New message mechanism on SIDs: instead of simply being string tags, messages are now individual shapes on the drawing page that can be added to, ordered in, and withdrawn from the message boxes on the corresponding connectors.
	- In consequence, the handling of the message connector has changed slightly. The message box no longer moves with the connector. It can be centered to the current middle of the connector.

- Reduced the number of connector shapes in the stencils. The individual trigger and receive transitions are gone. Instead, the connector type can be changed via the context menu or the shape data.

- Minor renaming of shapes

- Fixed minor issues with colors when copying and pasting ALPS shapes as graphics

- Introduced shape data for the layer/extension mechanism to shapes and work pages


2016-05-13: Release Notes 0.6.0-R

The new version of the S-BPM Visio Shapes has been released now.

Please note the following information.

Important: v0.6.0 is not backwards compatible with process models created with earlier versions. If you need to convert older models, you need to add shape categories or replace the old shapes with the new ones using the "Replace Shape" function. The conversion should best be conducted without active macros. The conversion may still cause problems. In important cases please contact: matthes.elstermann@web.de

Changes:

- Visio container functionality is now used for checkboxes and state groups, which greatly improves their handling (including features such as automatic adjustment of sizes and being able to move the complete content of a group/box simply by selecting the box)

- There is now only one checkbox shape. It can be switched from vertical to horizontal layout via an action in the right-click menu of the shape.

- The standard color scheme has been changed:
	- Red now denotes receive/waiting states, while green denotes sending/going-out states. The idea is that of a traffic light (red = wait, yellow = prepare yourself, do something, green = go). Note that this is the inverse of some standard settings in other programs.

- General improvements of error-prone shape behavior that appeared randomly, especially with larger process diagrams

- E.g. all shapes now have categories that allow easier handling programming-wise. The code has been revised to mostly execute depending on the categories, which is better performance-wise.
